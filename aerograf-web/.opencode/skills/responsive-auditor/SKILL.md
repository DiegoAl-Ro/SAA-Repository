# Auditoría Responsive y Accesibilidad
Usa esta skill tras implementar nuevas secciones visuales en el frontend.
## Reglas Obligatorias
- **Layouts Adaptables:** Usa CSS Grid o Flexbox con unidades relativas (`rem`, `%`, `clamp()`) para evitar desbordamientos horizontales en pantallas de 360px.
- **Accesibilidad:** Asegura contraste suficiente en botones e inputs, atributos `alt` en iconos/imágenes y navegación funcional por teclado.
- **Informe Final:** Al terminar de aplicar esta skill, incluye una breve verificación de los puntos comprobados.
