# Identidad de Marca AeroGraff AI
Usa esta skill siempre que crees o modifiques componentes HTML o CSS para AeroGraff AI.
## Reglas Obligatorias
- **Estética Urbana & Tech:** Mantén un diseño oscuro/neón profesional coherente con el resto de la web, usando variables CSS y evitando estilos en línea.
- **HTML Semántico:** Utiliza `<section>`, `<article>`, `<header>` y etiquetas de formulario accesibles (`<label>` asociado a cada `<input>`).
- **Tono Corporativo:** Redacta todos los textos visibles en español profesional orientado a clientes B2B (ayuntamientos, agencias y grandes marcas) que contratan murales con drones autónomos.
